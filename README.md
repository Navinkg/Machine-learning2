# 🏠 House Price Prediction using Machine Learning

## 📖 Overview

This project uses Machine Learning to predict house prices based on various property features such as area, bedrooms, bathrooms, floors, location, condition, and garage availability. Multiple regression models were trained and evaluated to identify the best-performing model for accurate house price prediction.

## 🎯 Objectives

* Clean and preprocess the dataset
* Perform Exploratory Data Analysis (EDA)
* Train multiple regression models
* Compare model performance
* Predict house prices accurately

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🤖 Machine Learning Models

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

## 📊 Model Evaluation

The models were evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* Feature Importance

## 📁 Dataset

* **Target Variable:** `Price`
* **Features:**

  * Area
  * Bedrooms
  * Bathrooms
  * Floors
  * Location
  * Condition
  * Garage

## 🔄 Workflow

```
Data Collection
      ↓
Data Cleaning
      ↓
EDA
      ↓
Feature Encoding
      ↓
Train-Test Split
      ↓
Feature Scaling
      ↓
Model Training
      ↓

      ↓
House Price Prediction
```

## 📈 Visualizations

* Price Distribution Histogram
* Correlation Heatmap
* Area vs Price Scatter Plot
* Location vs Price Box Plot
* Outlier Detection
* Feature Importance Plot

## 📌 Results

The regression models were compared using R² Score, MAE, and RMSE. The best-performing model was selected based on its prediction accuracy and error metrics, providing reliable house price predictions.
